## 2. 修复方案（按组）

### A 组｜覆盖缺口进报告（对应 P0-1、P0-5、P1-8）

**目标**：用户看到的报告必须能回答"这次到底测了什么、没测什么"。

| 文件 | 改动 |
|---|---|
| `packages/reporters/src/coverage.ts`（新增） | 定义 `CoverageInfo`：`{ pages, api, flows, plannedFlows, passedFlows, failedFlows, untestedFlows, empty, risks[], mapFailures[] }`；导出 `buildCoverageInfo(map, stats)` |
| `packages/reporters/src/markdown.ts` | `MarkdownOptions` 增 `coverage?: CoverageInfo`；`reportToMarkdown` 在 bug 列表**之前**输出「## 覆盖范围」区块：页面数/接口数/计划流程/已跑/失败；`plannedFlows===0` 时输出醒目横幅「⚠ 本次未识别到可测页面/接口 —— 0 个 bug 不代表项目健康」；列出 coverage risks 与 mapFailures；bug 为空时写明"未发现问题"而非留白 |

### 5.2 独立审核发现的问题（已全部修掉）

方案执行完后交给独立 verifier 审**实际 diff**，找出 6 个会误伤用户的问题：

| # | 问题 | 性质 | 修法 |
|---|---|---|---|
| 1 | **Web Settings 保存后 pricing 仍被抹掉** —— 只改了 `llmConfigToYaml`（会写），但 `ui.ts` 重建配置时根本没传 pricing | 假修复：写了写回函数但调用方没喂数据 | `ui.ts` 保存时合并 `existing.providers[name].pricing`；**补测走真实 HTTP 保存路径**（回退即变红，已验证） |

### 5.3 顺带修掉的两个真实缺陷

- **dev server 端口识别过窄**：只认 `localhost:数字`，`listening on 4321` 这种最朴素的输出会被漏掉 →
  用户明明看到服务起来了，Sentinel 却报 "No reachable project dev server"。现在四种常见格式都认，
  且子进程自己报告的端口（即使不在候选范围内）也会被采纳。
- **UI 测试等待预算过紧**：全量并行跑时（回测夹具占满 CPU）5s 不够，测试间歇性变红。
  断言未变，等待预算放宽到 15s —— 这是测试自身的脆弱，不是产品缺陷。
- **Next.js 冷启动会超时**：`.next` 缓存为空时首次编译实测要 40s+（且仓库在 iCloud 同步目录，更慢），
  原来的 45s 首页等待上限会让"刚 clone 下来第一次跑"的用户直接撞上 `首页连不上` → exit 2。
  已把上限放宽到 120s，并在等待期间每 30s 说一句在等什么（否则用户只看到一段沉默）。

  > 顺带说明：这轮排查出来的**真正收获**不是超时本身，而是失败信息。
  > 修复前用户只看到 `Browser preflight failed: goto: Timeout 15000ms`，
  > 修复后能直接看到子进程输出里的 `✓ Starting...` —— 一眼知道是"还在编译"而不是"端口错了"。

### 7.2 写测试时发现的一个真 bug（顺手修掉）

**symlink 路径会让"本项目的服务"被误判成"别人的服务"**。

`verifyProjectIdentity` 原来直接比字符串：

```ts
const resolved = resolve(cwd);      // lsof 报的真实路径
const root = resolve(projectRoot);  // 用户传进来的路径
```

macOS 上 `lsof` 报的是**真实路径**（`/tmp` → `/private/tmp`、`/var` → `/private/var`），
而用户传进来的 `projectRoot` 可能是软链路径。两者字符串不等 → 明明是同一个项目，
却判成"不是本项目" → 本该复用的 server 被误判为外来服务，白白另起一个。

修法：比较前先解 symlink（`realOrSelf()`，`realpathSync` 失败则回落 `resolve`）。
**这个 bug 是写第 2 条测试时暴露的** —— 只跑真实路径才能发现，纯字符串比较的单测测不到。
